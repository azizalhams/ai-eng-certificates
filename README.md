### AI-901 — Azure AI Fundamentals

#### 💬 Foundry Chat Client
A lightweight Python chat application built using the Azure AI Foundry SDK. Demonstrates basic model deployment, prompt construction, and response handling.

**Tech:** Python · Azure AI Foundry SDK · REST API

**Status:** 🔄 In Progress

### AI-103 — Azure AI App and Agent Developer Associate

#### 📚 RAG Application
A Retrieval-Augmented Generation pipeline that grounds an LLM's responses in custom documents. Built with Azure AI Search for indexing and retrieval, and the Foundry SDK for generation.

**Tech:** Python · Azure AI Foundry · Azure AI Search · RAG

**Status:** 🔄 In Progress

---

#### 🤖 Single Agent
A fully functional AI agent built using Azure AI Agent Service. The agent can reason across multiple steps, use tools, and maintain memory across a conversation.

**Tech:** Python · Azure AI Agent Service · Foundry SDK

**Status:** 🔄 In Progress

---

#### 🧠 Multi-Agent Workflow
An orchestrated multi-agent system where a coordinator agent delegates subtasks to specialized sub-agents. Demonstrates real-world agentic AI architecture patterns.

**Tech:** Python · Azure AI Foundry · Multi-Agent Orchestration

**Status:** 🔄 In Progress

---

#### 👁️ Computer Vision & NLP Pipeline
A set of Python applications demonstrating Azure AI Vision (OCR, object detection, image classification), Azure AI Language (sentiment analysis, entity recognition, summarization), and Azure AI Speech (speech-to-text, text-to-speech).

**Tech:** Python · Azure AI Vision · Azure AI Language · Azure AI Speech

**Status:** 🔄 In Progress

---

#### 📄 Document Intelligence Pipeline
An information extraction pipeline that processes PDFs, forms, images, and audio files using Azure Content Understanding — extracting structured data from unstructured inputs.

**Tech:** Python · Azure Content Understanding · Document Intelligence

**Status:** 🔄 In Progress
