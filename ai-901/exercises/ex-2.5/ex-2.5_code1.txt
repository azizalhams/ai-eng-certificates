To submit a prompt that analyzes an image, you can modify the input parameter to include both text and image content, as shown here:

 from openai import OpenAI
    
 endpoint = "https://your-project-resource.openai.azure.com/openai/v1/"
 deployment_name = "gpt-4.1-mini"
 api_key = "<your-api-key>"
    
 client = OpenAI(
     base_url=endpoint,
     api_key=api_key
 )
    
 response = client.responses.create(
     model=deployment_name,
     input=[{
         "role": "user",
         "content": [
             {"type": "input_text", "text": "what's in this image?"},
             {"type": "input_image", "image_url": "https://an-online-image.jpg"},
         ],
     }],
 )
    
 print(f"answer: {response.output[0]}")
